# DigiTools

## Project Description

DigiTools is a modern web application where users can explore and purchase useful digital tools. The project includes product cards, a shopping cart, dynamic cart updates, and interactive buttons to provide a smooth user experience.

## Technologies Used

* React.js
* JavaScript (ES6+)
* Tailwind CSS
* DaisyUI
* React Toastify
* JSON
* Vite

## Features

1. **Dynamic Shopping Cart** – Users can add products to the shopping cart, view selected products, and see the total price.

2. **Interactive Product Selection** – Users can select products using interactive Buy Now buttons that change their appearance when selected.

3. **Toast Notifications** – Users receive notifications when adding products to the cart, removing products, and proceeding to checkout.
